Experience

Research Engineering Intern – Deep Learning for Ionospheric Scintillation Mitigation in SAR Imagery

National University of Singapore (NUS), Singapore — Jan 2026 – Present

  • Developed the deep-learning component of BubbleNet, a physics-informed research project restoring L-band SAR imagery (e.g. ALOS/PALSAR) degraded by ionospheric scintillation — targeting a submission to ISAP 2026.
  • Designed and adapted a complex-valued neural network (CVNN) predicting the scintillation indices S4 (intensity) and σφ (phase) from complex SAR signal representations, extending it from single-output to multi-input, dual-output regression.
  • Built a physics-informed pipeline coupling deep learning with a phase-screen model (Carrano et al., 2012): CVNN index prediction → analytic regeneration of the ionospheric transfer function → U-Net image denoiser, validating each stage against synthetic physical ground truth.
  • Engineered the data and training stack in PyTorch (native complex tensors): refactored complex-valued HDF5 inputs, built a precompute step caching ~5 GB in RAM for ~5× faster training, and extended losses and per-output metrics (R², RMSE, MAE); ran experiments on a PBS HPC cluster (CPU/GPU, A40).
  • Reached R² = 0.980 (RMSE = 0.020) on S4 prediction, outperforming random-forest and real-valued network baselines; authored the project's technical documentation and coordinated the data interface with the physics team.

Software & Data Engineering Intern – Dynamic Satellite Database for Space Surveillance

ONERA (French Aerospace Lab), Palaiseau, France — Jun 2024 – Aug 2024

  • Built OBELIX, a Python ETL (extract–transform–load) pipeline supporting ONERA's space-surveillance work, aggregating data on satellites and orbiting objects from several heterogeneous sources: Gunter's Space Page (web scraping with BeautifulSoup), the UCS satellite catalogue, Two-Line Element (TLE) sets from Space-Track and McCants, and DORIS (CNES) COSPAR identifiers.
  • Processed the TLE sets with Skyfield to derive orbital parameters and classify each object's orbit using ESA terminology (LEO, MEO, GEO, SSO, GTO, HEO, VLEO…), including sun-synchronous-orbit detection via J2 nodal precession and conversion of NORAD Alpha-5 identifiers.
  • Centralised the data in a MongoDB database built on a hub-and-spoke model around a pivot Satellite collection (keyed by NORAD / COSPAR), with deduplication and integrity checks that flag identifier conflicts and retain only the most recent TLE per object.
  • Exposed the catalogue through a FastAPI REST API offering list and per-field queries, whitelisted field updates, and a custom query language with comparison operators, sorting and result limits translated into MongoDB queries.
  • Documented the schema, scripts and procedures so the system could be maintained and extended by the team.
